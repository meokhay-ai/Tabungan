# Tabungan User Feedback Log

This log tracks the 50-user Level 5 feedback cohort for Tabungan. Each row links one
named user to a real Stellar testnet public key, a role, and a written feedback
note. The same roster is mirrored in the linked [Google Sheet response export](user-feedback-form.md)
and `docs/submission-proof.json`.

Wallet public keys are generated by `scripts/generate-test-wallets.mjs` and funded
via Friendbot. Roles follow the Tabungan family-allowance vault model: `parent`
(deposits XLM into the contract and sets per-recipient allowances), `recipient`
(claims their share of the allowance from the contract), or `admin` (pause,
unpause, upgrade, and view the system).
